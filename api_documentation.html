API Documentation

Reference guide for Sakr Manning Agency - Document & Verification Endpoints

POST /api/documents/

Create Document / Quick Apply

Primary access point for candidates ("Quick Apply"). Uploads a CV or other document.
- If the email provided does not exist in the system, a new User account is automatically created with the role 'Employee' and status 'Pending'.
- If the email exists, the document is linked to that user.
- Default document status is 'Pending'.

Request Body (Multipart/Form-Data)

Field Type Required Description
title String Yes Document title (e.g., "CV", "Passport")
file File Yes The document file. Allowed extensions: .pdf, .docx
name String Optional* Full name of the applicant. *Required for new applicants.
email Email Optional* Email address. *Required for new applicants to create account/link data.
phone_number String Optional Contact phone number.
position String Optional Rank/Position (e.g., "Master", "Chief Officer"). See available choices.
POST /api/documents/{id}/set_status/

Set Document Status

Manually approve or reject a document.
- Setting status to "Active" triggers the following automated workflow:

  1. Generates a unique 12-digit User ID (if not already present).
  2. Syncs document data (Name, Phone, Position) to the User's profile.
  3. Sends a Welcome/Verification Email to the user with a secure link.

Strict Permissions: Only Admin, HR Manager, or Recruiter roles (or Superusers) can perform this action. Employees cannot approve their own documents.

Request Body (JSON)

Field Type Required Description
status String Yes New status value.
Choices: Pending, Active, Blacklist

Example Payload

{ "status": "Active" }
GET /api/documents/{id}/download/

Download Document

Secure file download.
Retrieves the actual file content (PDF/DOCX/Image) associated with the document record. Browser will attempt to display inline or download depending on file type.

Parameters

Parameter Type Required Description
id Integer Yes The unique ID of the document to download.
GET /api/documents/

List Documents

Retrieve a list of uploaded documents.

Role-Based Access Control:

  • Admin / HR Manager / Recruiter: Can view ALL documents in the system.
  • Employee: Can ONLY view documents that they uploaded themselves.

POST /api/personal-documents/

Create Personal/Travel Document

For authenticated users/employees only.
Upload specific travel or identity documents (Passport, Seaman's Book, Visa, etc.) to your profile. Unlike the "Quick Apply" endpoint, this requires specific metadata like issue_date, expiry_date, and document_type.

Request Body (Multipart/Form-Data)

Field Type Required Description
document_type String Yes Type of document. Choices include: Passport, Seaman's Book, EU national ID, etc.
document_number String Optional Document number (e.g., Passport Number).
issue_date Date Optional Format: YYYY-MM-DD
expiry_date Date Optional Format: YYYY-MM-DD
issuing_country String Optional Country where the document was issued.
file File Optional Scanned copy of the document (PDF, JPG, PNG).
user Integer Optional* User ID. *Required if Admin/HR is uploading for another user. Employees automatically assigned to self.
GET /api/verify-email/{uid}/{token}/

Verify Email

Public verification endpoint.
This URL is generated and sent via email when a user is approved (Document set to "Active"). Visiting this link validates the user's email address and activates their account for login.
Note: This is a GET request usually performed by the user clicking a link in their email client.

Parameters (URL Path)

Parameter Type Required Description
uid String (Base64) Yes Base64 encoded user ID.
token String Yes One-time verification token.
