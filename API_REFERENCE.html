Authentication

Login

  • POST /api/login/
  • Body: {"email": "...", "password": "..."}
  • Response: {"access": "JWT_TOKEN", "refresh": "..."}
  • Permission: AllowAny

    • Register

  • POST /api/users/register/
  • Permission: AllowAny

    • Logout

  • POST /api/users/logout/
  • Permission: IsAuthenticated

    • Refresh Token

  • POST /api/login/refresh/
  • Body: {"refresh": "REFRESH_TOKEN"}
  • Permission: AllowAny
